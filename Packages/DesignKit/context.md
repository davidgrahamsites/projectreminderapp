# DesignKit — context
The three apps must feel like one product. The user chose a neumorphic, purple-accented look (soft
dual shadows, rounded SF type, pill controls, light/dark) from a reference UI kit — overall look
only, not every widget. DesignKit centralizes those tokens + the signature ProjectCard/ProjectRow
("Now / Up Next") so Mac, iPhone, and Watch share one identity. Added in the final design phase
after the functional apps (A/B/C) were built.
